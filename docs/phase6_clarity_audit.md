# Phase 6 Clarity Audit

## Current issues
- Cricket scenario reasons are cleaner than before but still include generic lines in some paths (for example neutral venue wording and baseline phrasing).
- Historical matches still display source/freshness text that reads like live telemetry, which weakens trust for archived results.
- Scenario cards include both branches, but the main chart still centers a single value and visually underrepresents two-team outcomes.
- Fallback/runtime status is accurate but still visually prominent in summary badges.
- Player panels are improved, but the "Top Match Impact" label and repeated micro-phrasing can be tighter.

## Trust/clarity cleanup for this pass
1. Tighten scenario reason wording with clearer comparative team/context statements and less generic fallback wording.
2. Simplify metadata display for historical state and only show live freshness/source when it adds value.
3. Make scenario chart and card presentation explicitly two-team oriented without redesigning layout.
4. Soften fallback badge prominence while keeping status visible.
5. Keep player panel concise with cleaner label wording and compact reason rendering.
